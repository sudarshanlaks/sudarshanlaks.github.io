What the data shows (all channels, all categories)

  • The current statistical forecast has 15.6% error, 3.4 points better than the naive baseline of 19.0%, so it earns its place.
  • No simple method beats it overall. The closest is exponential smoothing at 16.0%.
  • Beverages are the exception: seasonal exponential smoothing has 16.8% error against 19.4% for the current forecast, 2.6 points better, because Beverages have a strong summer pattern.
  • In Food, Home Care and Personal Care, exponential smoothing is within 0.5 points of the current forecast, so there is little to gain.

Recommendation

Switch Beverages to seasonal exponential smoothing and keep the current forecast for the other categories. The choice was made on the same 21 test months, so confirm it on the next three months before rolling it out.

WAPE = sum of absolute errors / sum of actual sales. Bias = sum of (forecast - actual) / sum of actual. Each method forecasts a month using only earlier months. Simple methods: naive, seasonal naive, 3-month moving average, exponential smoothing (alpha 0.3), seasonal exponential smoothing.
